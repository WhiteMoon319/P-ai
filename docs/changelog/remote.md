# 变更日志

## 发布：v0.88.0

## 功能

- 桌面操作新增后台操作模式与「移动鼠标」动作：助手无需切换窗口、不抢焦点即可对指定后台窗口截图、点击（含双击）、填文本、读文本、滚动与发按键，找不到目标时给出候选清单；脚本中途出错会说明已执行到哪一步。
- 后台任务监控面板：AI 启动的后台命令可在侧边栏实时查看运行状态、持续时长与输出进展；任务进度实时同步到网页端与 VS Code 侧边栏，切回前台后自动刷新为最新状态。
- AI 修改文件不再等待审批，删除文件改为移入系统回收站（macOS 为废纸篓），误删后可以找回；终端命令审批要求 AI 填写命令用途，审批卡会展示说明。
- 输入面板与提问卡统一为双层卡片，桌面与手机共用同一套布局，等待队列以「露头」方式提示，排队消息不再漏显。
- 右侧栏预览卡片墙重做，新增「历史委托」卡与「计划预览」卡；Git 卡会随 IDE、终端里的文件改动自动刷新。
- 会话列表新增精简视图模式，运行中的会话有更明显的状态提示。
- 新增「深度回忆」工具，可以从历史会话里找回某个话题的来龙去脉。
- 接入 OpenCode Go 端点时自动携带会话标识；Code X 支持 GPT-6（gpt-6-astra）。

## 修复

- 修复压缩重开对话后气泡停留在流式状态、流式回复期间尾部留白被冻结、思考与执行字符数停在旧值的问题。
- 修复会话忙碌时无法打开上下文占用入口，以及上下文占用与词元账单取数不对的问题。
- 修复从「批准计划执行」等非发送入口继续会话时回复收不到、界面卡在等待的问题。
- 修复调度日志把一轮工具循环的多轮合并成一轮的问题，现在按轮次分别展示。
- 修复 Git 面板反复自动刷新停不下来、运行日志窗口不再跟随底部的问题。
- 修复足迹墙「今天」视图凌晨时段漏统计、远程 IM 私聊消息归属错误、微信图片与文件收不到的问题。
- 修复便携版更新时程序被占用导致替换失败的问题，现在会等待程序退出后重试。
- Android 端发消息一直收不到回复、模型列表也加载不出来：请求缺少证书链导致 HTTPS 握手失败，现已恢复。
- Android 端「Android 专属」设置页内容超出屏幕后无法滑动，现在可以正常滚动。

## 性能

- 隐藏弹窗中的原始消息 JSON 与代码全文预览改为打开时才渲染，打开含超长思维链或大代码块的消息后滚动聊天不再周期性卡顿。

## 发布：v0.87.0

## 功能

- 右侧栏改为工作区预览卡片墙：左上角下拉按钮变成预览入口，Git 更改、已打开文件、工作目录、新建追问、追问会话、后台终端、委托、任务、最近工具各成一张卡片，没有内容就不占位；右侧栏同时加宽以容纳两列。
- 部门与人格归属改为双向勾选：人格页新增「归属部门」，与部门页的勾选人格对称；保存时不再替你自动补齐部门成员，空缺只提示、不阻断。
- 人格回忆方式改为三档独立说明：「全功能 / 仅主动回忆 / 完全关闭」，说明随所选档位切换；选「完全关闭」时记忆不再写入、也不再召回。
- 行内代码与链接改为按主题混色：去掉行内代码的不透明白底，深浅主题下自动调制明暗，不再出现成片代码盖住文字。
- 新建会话页与追问空态的背景光斑改为跟主题取色的辉光：新建会话页从头像主色采样，追问空态收成一团主题色辉光放在按钮身后。

## 修复

- 切换人格后输入面板与首条消息仍沿用旧人格，要发出第一句才刷新，现在切换即时生效。
- macOS 上每次调用桌面操作都会弹出辅助功能授权请求，现在改为静默检查权限，缺失时给出可直接执行的开启指引。
- 从「更多」展开的全量人格卡片墙里选中人格后会立刻收起，连续比较要反复展开，现在选中后保持展开。
- 固定 macOS 发布签名，已授予的系统权限许可可以跨版本复用，升级后不必重新授权。

## 发布：v0.82.0

## 功能

- 新增内置"人力部"部门：它负责招募专家，不可删除，名称、简介、办事指南与权限均内置固定，仅负责人格可以在部门设置里自行更换。
- 选专家面板的"更多"现在会直接在原位展开全部专家，不再弹出窗口；面板右下角新增"招募专家"入口，点击即可把草稿会话切到人力部，并在部门卡片上标注"招募功能属于实验功能，尚未完善"的提示。进入人力部后卡片列表只保留人力部一张卡并给出"返回"，返回会自动切回你最近用过的专家。你可以在人力部会话里跟着对话指引，一步步完成新部门与新人格的查重、创建与绑定，并引导你用新专家开会话。
- 供应商页的模型测试结果会显示在窗口底部状态条：单个测试完成立即上报连通或失败，测试全部跑完再汇总一次"成功/失败"数量；API Key 列表上的状态圆点改为可点击，点击会再次把该条的测试结果上报到底部状态条。
- 模型卡的显示名与模型 ID 现在自动对齐：修改模型 ID 后显示名会跟随重置为新 ID；修改显示名时会弹窗提示"只改显示名、不影响调用的模型 ID"。
- Android 端设置页新增「Android 专属」栏：集中放置 Linux 沙盒工作区管理（初始化 / 导入压缩包 / 修复 / 重置 / 关闭、文件管理器）、设备控制能力开关与终端执行域（Linux / Android）切换。

## 修复

- 保存供应商设置后，"保存"按钮不再自己弹回高亮状态：保存会先等在途的模型信息解析完成，落盘的就是最终形态。
- 聊天窗口右下角的时间轴按钮改为常驻，且"回到最底部"与时间轴两个按钮整体上移，不再遮挡底部工作条。
- 新建对话页选择文件夹恢复为全屏弹窗选择器，不再被内嵌卡片裁剪成面板内的小窗口。
- 手机端（窄窗口）文件面板的目录树改为全屏浮层：点开后覆盖在文件区上方而不是挤占侧栏，点浮层空白处即可收起，浏览文件与目录切换互不遮挡。
- 流式回复的空档期不再让思考面板抢跑：调度状态文案区分为"请求中"与"思考中"，等待调度时只在上方显示一行请求状态，不再弹出空的思考 / 工具面板。
- 聊天右侧的阅读面板在窄窗口下打开目录树时，目录树会占满整个面板、文件内容区让位，不再出现半透明的遮罩浮层，浏览目录与阅读文件切换更干净。
- Android 端状态栏改为纯黑沉浸、内容直接延伸到小白条之下：状态栏区域为黑色、图标白色，聊天输入区顶到屏幕底部不再留黑边。

## 重构

- 聊天重试改为空回与 429 双轨独立状态机：空回（含仅思维链）与 429 限流各 3 次线性独立计数、固定等待（5 秒 / 30 秒），成功随请求栈清零；404 等明确不重试，其它是直失败；其它错误类型预留枚举扩展口。
- 设置页的 MCP 配置入口中文名改为"连接器"。
- Android 端跟随上游退役独立「工具」页：助理空间目录并入聊天设置的「执行终端」区块、内置工具清单并入调试页；Android 专有的沙盒与设备控制内容迁至新的「Android 专属」栏。
- 移除 Android 端「远程前端模式」（手机作为电脑 PAI 前端）与设置页的网络访问入口：该功能已失效，相关连接表单、跨端桥接与明文流量放开一并删除。
