## 发布：v0.15.5

## 修复

- **goal 续跑完成态收口**：移除 `round_completed` 对前端 activation 门禁的错误依赖，goal 自动续跑在消息正式完成后会正确结束忙碌态，不再出现已经出正式消息却仍显示“正在输入”的情况。
- **goal 流式旧包拒收**：前端在收到完成信号后会拒收同轮次残留的旧流式增量，避免已完成消息再次把草稿气泡、思考中状态或停止按钮拉回活动态。
- **goal 草稿定位与测高**：助理草稿统一追加到消息尾部，正式消息完成时不再复用流式草稿的渲染身份，减少系统消息插入后出现的气泡错位、跳动和虚拟列表测高残留。
- **窗口恢复旧 busy 残留**：聊天窗口最小化、还原或重新激活时不再盲信前端残留的忙碌态，而是以后端运行态快照为准，避免流式已完成但界面仍卡在旧 busy 状态。
- **目标续跑投递语义**：目标续跑消息改为助理角色并延后一秒投递，避免把 persona 名为“系统”的消息误当成 LLM system prompt，同时减少续跑消息在用户刚看清上一条回复前抢占视线。
- **归档重建口径**：rewind 与归档链路的 `body_text_length` 重建改为使用统一口径，减少会话归档统计和后续重建不一致的问题。

## 发布：v0.15.0

## 新增

- **聊天窗口**：Markdown 渲染支持注脚、README 图片徽章和本地相对图片路径，阅读文档、README 与模型输出时更接近原始排版。

## 优化

- **聊天窗口**：流式 Markdown 改为增量解析，只重算尾部未完成内容，长回复、代码块、表格和工具引用的显示更顺滑。
- **聊天窗口**：引用块、代码块、表格、文档标题和深色主题细节统一打磨，阅读层级更清楚。
- **聊天窗口**：历史消息加载触发、图片/表情显示、图片预览关闭按钮和右键选区菜单体验进一步收口。
- **远程联系人**：统一远程联系人消息读取、身份提示词与模型预览，OneBot 消息段渲染和图片显示更稳定。
- **任务侧栏**：聊天侧任务创建卡、任务列表与工具评估侧栏复用同一套交互，任务管理入口更一致。
- **文件阅读器**：重构文档阅读、渲染和滚动交互，补齐独立文件窗口的多语言注入。

## 修复

- **启动稳定性**：修复首次启动或删除最后会话后 ready 消息仓库恢复链路中的会话锁重入死锁。
- **聊天窗口**：助理最终正文与思考文本会原样持久化，避免空白、缩进或空正文在提交阶段被改写。
- **聊天窗口**：修复流式纯换行内容被丢弃、自定义语言代码块底色露缝、超长错误提示挤走关闭按钮等问题。
- **工具评估**：补丁预览现在只显示实际改动内容，并复用真实命中行范围，行号和评估意见展示更准确。
- **快速设置与选择器**：补齐快速设置步骤文案，统一部门人格选择器并修正头像接线。
