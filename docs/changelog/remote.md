## 发布：v0.19.0

## 功能

- 功能（config）：所有模型选择器统一展示模型思维等级，关闭思考时显示“不思考”，便于在快速设置、配置页和聊天相关入口中直接区分同模型的不同推理档位。
- 功能（chat）：启动加载遮罩补充阶段进度提示，启动过程更可感知。

## 维护

- 维护（updater）：自动更新检查统一收口到后端 8 小时节流，减少重复触发。

## 修复

- 修复（config）：软废弃删除供应商或模型后，会同步清理失效绑定、跳过已废弃供应商，并在历史用量读取模型名缺失时按旧 ID 自动回填；若已无法解析则写入 `unknown`，避免统计与配置入口被脏引用卡住。
- 修复（chat）：修正助理气泡左右留白不对称、回复期间对输入工具栏的误禁用，以及底部弹性区域未给 Todo 可见空间预留的问题。
- 修复（sidebar）：侧边栏流式消息重新收口到真实 assistant 消息 ID，避免消息归属错乱。

- **移除会话锁定对运行态的错误依赖**：会话锁定状态不再错误地依赖运行时缓存，避免切换会话时异常锁定。
