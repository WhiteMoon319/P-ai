# 变更日志

> 此文件由 `pnpm changelog:build` 自动生成，展示最近版本的完整说明。

## 发布：v0.40.0

- 修复：发送消息时不再在附件提示阶段检查文件是否存在，减少 prompt 构建阶段的磁盘访问和额外耗时。
- 修复：群聊远程应答默认不再对超长回复发起二次快速模型改写，模型回复完成后直接进入落库与外发流程。
- 修复：文件传输入口收口为路径/分块统一方案，粘贴文件不再走整文件 base64 主路径，并补上附件超时清理与提交竞态保护。
- 修复：会话草稿会保留已落盘但尚未生成 base64 预览的图片附件，切换会话后不再丢失。
- 新增：加入独立文生图功能域与“图像生成”工具，支持本地 ComfyUI、OpenAI GPT Image、xAI Grok Imagine、火山方舟 Seedream 和 Gemini Nano Banana 2；配置页可管理独立供应商/模型与 ComfyUI 工作流，生成结果安全保存并显示自 PAI 助理空间。
- 新增：加入独立 `image_edit` 图像编辑工具，支持对话附件驱动的局部修改、局部重绘、扩图和多图融合，并按供应商能力复用现有生图模型与认证链路。
- 调整：生图模型默认宽高比统一为 `1:1`，默认分辨率统一为 `512x512`；供应商模板和设置页测试预设同步更新。
- 调整：生图供应商默认超时改为 600 秒，配置上限收敛为 10 分钟，移除原先 300 秒默认超时。
- 调整：生图工具参数收敛为“提示词 → 分辨率”，移除无独立意义的宽高比参数，并向 LLM 明确默认分辨率 `512x512`。
- 优化：默认生图模型与多模态分析模型选择“不配置”时，不再向模型提供 image_generate / read_media 工具。
- 修复：清理 DaisyUI v4 残留类 form-control / label-text（v5 已移除），修复配置页、委派面板、工作目录选择等多处标签与输入框挤在同一行的布局错乱。

## 远程联系人更好用

- 远程会话新增能量仪表盘，可直接看到当前能量、恢复速度和在线状态；回到前台后会自动补齐期间错过的状态更新。

- 图片、音频和文件现在统一按原始顺序展示；单个附件解析失败时会保留文件提示，不会影响整条消息或委托继续执行。

## 工具与模型兼容性

- 工具权限按当前会话、联系人能力和 MCP 状态统一校验，未授权工具不会再被错误提供；局部读取或缓存异常也只跳过受影响工具。
- Gemini 在调用图片、音视频等工具后可以继续正常回复，不再因内部续接信息缺失而中断。
- 图片和音频读取会根据手动协议、服务地址和模型名自动选择正确的供应商接口，兼容更多百炼、DeepSeek、火山、Kimi、Mimo、QWEN 及 OpenCode Go 配置。
- 远程委托发送 Markdown 图片时会直接发送实际图片，并自动去掉模板附带的文件名来源文字。

## 优化

- 主题列表移除粉彩，改为官方秋日主题，并新增官方幻想主题；官方预设主题不再被自定义配色覆盖。
- 设置窗口最小尺寸限制为 `900x600`，避免异常布局恢复或误操作缩放后变成过小窗口。
- 聊天 Markdown 与代码块字体回到 DaisyUI/Tailwind 默认控制，代码块展开预览复用统一代码显示器，并恢复行号显示。
- 远程联系人回复工具集更聚焦，普通文字统一走最终回复自动外发，联系人专用工具保留附件发送。
- 会话控制面板到达底部时立即显示，离开底部后短暂延迟隐藏，减少快速滚动时的闪烁。
- 面板标签改为 Chrome 式均分收缩布局，窄窗口下更易使用；归档与标签栏视觉样式更统一。
- 工具调用预览统一为单一列表样式，连续工具标记会合并显示，思考与工具明细可同时展开。
- 运行日志按等级着色，并统一关键运行日志的等级和中文状态文案，排查问题更直观。
- 用量概览和委托状态改用轻量缓存与快照读取，减少打开设置页和切换委托列表时的等待。
- Codex 回复默认使用较低可见详略度，在保留推理能力的同时减少冗长输出。
- Web 侧边栏恢复会话时按差量同步列表，只在会话落后时重新接管快照。
