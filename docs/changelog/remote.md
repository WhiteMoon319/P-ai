# 变更日志

> 此文件由 `pnpm changelog:build` 自动生成，展示最近版本的完整说明。

## 发布：v0.36.0

## 远程联系人更好用

- 远程会话新增能量仪表盘，可直接看到当前能量、恢复速度和在线状态；回到前台后会自动补齐期间错过的状态更新。
- 群聊默认更安静：助手会先判断是否真的需要发言，减少无关插话、重复回复和对别人消息的点评。
- 群聊重新加入、持续巡检和自动回复的衔接更可靠，网络波动或处理超时也不会重复发送同一条消息。
- 新发现的联系人默认关闭收发，确认开启后才会继续处理消息，避免误触发。
- 联系人和群聊日志改为显示渠道名、联系人名和内容摘要，更容易定位问题，也不会暴露内部编号。

## 聊天、文件与侧边栏

- 图片、音频和文件现在统一按原始顺序展示；单个附件解析失败时会保留文件提示，不会影响整条消息或委托继续执行。
- 会话控制面板支持右键切换 IDE 文件和侧边栏文件标签；VS Code 侧边栏会同步当前打开的文件，关闭文件后候选标签会及时清理。
- 左右侧栏在屏幕空间足够时会自动向窗口外展开，空间不足时保持原有布局，反复开关也不会让窗口越变越宽或位置跳动。
- 上下文压缩会保留助手在工具阶段已经生成的正文，保留对话也只继承当前目标内容，减少无关历史和内容丢失。
- 任务完成后会正常回到助手回复流程，不会因为完成一个任务而提前终止整轮对话。

## 工具与模型兼容性

- 工具权限按当前会话、联系人能力和 MCP 状态统一校验，未授权工具不会再被错误提供；局部读取或缓存异常也只跳过受影响工具。
- Gemini 在调用图片、音视频等工具后可以继续正常回复，不再因内部续接信息缺失而中断。
- 图片和音频读取会根据手动协议、服务地址和模型名自动选择正确的供应商接口，兼容更多百炼、DeepSeek、火山、Kimi、Mimo、QWEN 及 OpenCode Go 配置。
- 远程委托发送 Markdown 图片时会直接发送实际图片，并自动去掉模板附带的文件名来源文字。

## 发布：v0.35.0

## 聊天更稳定、更顺手

- 修复后台处理、切回前台、切换会话时流式回复偶尔丢失、重复或最后一条没有及时刷新的问题；桌面端、侧边栏和移动端都会优先续接当前回复，而非整页刷新。
- 支持多个追问会话并行存在，切换后仍能回到各自正确的流式进度；输入框草稿不会再被运行状态错误锁住，新建会话的第一条回复也更稳定。
- 可以把消息复制成图片；输入面板可选择是否显示文件标签，文件引用和标签显示也更准确。

## 远程联系人更自然

- 联系人设置支持复制和粘贴，方便将处理部门、应答策略等配置复用到其他联系人。
- 每个联系人都可以过滤指定消息开头，默认过滤 `# / %`，指令消息和 Markdown 标题不会再进入会话或触发回复。
- 远程私聊与群聊使用不同的沟通规则：私聊只随 Todo 的关键变化同步进度；群聊安静执行、只在开始和完成时发言，并更贴近群友当前的讨论氛围。
- 私聊联系人固定采用“始终入场”，不会再因遗留的入场选项而漏接消息。
- 群聊秘书、并发应答和防抖流程更可靠，减少重复话题、顺序错乱和不必要的打断；判断超时或失败时也不会误触发回复。

## 文件与工具体验

- 文件阅读器支持对选区执行操作、在聊天中引用选区，并更准确地展示目录、真实文件图标和 WSL 路径。
- 工具与终端的大段输出会自动聚合和节流；图片、音频、视频解析增加分级超时保护，长任务更不容易卡住或挤占对话内容。
- 修复发送链路在新会话首发时可能触发的闪退问题，降低调度准备阶段的内存与栈压力。

## 其他改进

- 优化前台恢复、归档列表与远程联系人会话的刷新效率，减少切换和恢复时的等待。
- Web 侧边栏同步了相应的聊天与联系人体验改进。
