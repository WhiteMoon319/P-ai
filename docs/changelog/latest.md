# 变更日志

## 发布：v0.92.0

## 功能

- **PAI CLI（Beta）**：终端里直接运行 `p-ai run "<任务>" --model <配置>` 即可完成一整轮对话（含多轮工具调用），桌面端配置好的 skill 与 MCP 在 CLI 里同样可用。
- **聊天操作区重做**：输入框上方新增流式预览条，生成时按阅读节奏逐行展示思维链与最新正文，并接管「回到最新」入口；时间线按钮、预览条、工作区栏收进同一个操作区，贴底与上翻时上下两排按状态切换。
- **能力商店**：跨魔搭、Smithery、MCP Registry、ClawHub 检索 MCP 连接器与技能并一键安装，默认关闭、需要密钥的在安装前填写；技能支持整体启用/关闭，自定义技能可改名、编辑与删除。
- **配置页改版**：技能、供应商、人格、连接器、渠道等模块改为卡片概览 + 二级详情；各页头部统一为面包屑 + 下划线页签。
- **部门改为人格组织树**：配置页不再有「部门」与「部门树」页，原来由部门承担的委托下级、驱动模型、权限范围、办事指南全部改由人格承载，旧配置启动时自动迁移；人格页重做为「资料 + 能力 + 加载顺序」，可调整技能注入顺序、按工具逐项勾选权限、关闭系统准则注入。
- **会话时间线改版**：时间线入口改为常驻按钮，打开即整屏竖排历史，点任一条直达该消息；悬停蛇形时间线恢复并在尾部加预览点。
- **主页卡片墙扩充**：新增「Git 提交」卡与「历史委托」卡，Git 卡随 IDE / 终端里的文件改动自动刷新。
- **文件与链接右键菜单**：文件可在侧边打开、在 VS Code 打开、定位、另存为、复制路径；网页可在浏览器打开或复制链接。
- 支持读图的模型可直接接收本地图片原图，不再先经过文字转述。

## 修复

- 修复压缩重开对话后气泡停留在流式状态、流式期间尾部留白被冻结、思考与执行字符数停在旧值的问题。
- 修复切换会话后助理气泡丢失流式样式、Git 更改区串到其他会话仓库、打开会话不落在最新消息。
- 修复上下文占用与词元账单取数不对、会话忙碌时无法打开上下文占用入口。
- 修复从「批准计划执行」等非发送入口继续会话时回复收不到、界面卡在等待的问题。
- 修复调度日志把一轮工具循环的多轮合并成一轮的问题，现在按轮次分别展示。
- 修复 Git 面板反复自动刷新停不下来、运行日志窗口不再跟随底部的问题。
- 修复足迹墙「今天」视图凌晨时段漏统计、远程 IM 私聊消息归属错误、微信图片与文件收不到的问题。
- 修复松开录音热键后仍持续录音（切屏场景），录音状态改为窗口级提示、失败原因不再被覆盖。
- 修复便携版更新时程序被占用导致替换失败的问题，现在会等待程序退出后重试。
- macOS 26 上模拟组合键导致主线程崩溃的问题已修复。
- Android 端对话消息收发与模型列表加载的证书链问题已修复，并随本版全面跟进上游功能（组织树、能力商店等均可用）。

## 性能

- 隐藏弹窗中的原始消息 JSON 与代码全文预览改为打开时才渲染，打开含超长思维链或大代码块的消息后滚动聊天不再周期性卡顿。
