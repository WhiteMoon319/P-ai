# 变更日志

## 发布：v0.36.1

## 远程联系人更稳定

- 修复远程联系人私聊发言可能重复的问题。
- 远程联系人私聊恢复为正确的引导调度链路，不会再把不该进入本轮的问题历史带进来。
- 远程消息入站不再做记忆召回，联系人私聊和群聊的处理链路更直接，也更符合预期。

## 文件引用与 IDE 上下文更顺手

- 输入面板里的附件、IDE 文件标签和引用展示重新收口，显示更统一，也不容易再出现重复、丢失或被吞掉的情况。
- 同一文件有选区时会优先同步带行号的选区；没有选区时只同步当前文件，不再把编辑器可视区域整块带进上下文。
- 超长文件引用现在会自动收敛成路径和行号，减少无关正文挤占上下文。
- 侧边文件标签入口已默认关闭，同时会忽略旧偏好和跨窗口开启事件，避免误触。

## Markdown 图片与放大预览更好用

- 修复文件浏览器里 Markdown 图片的懒加载问题，长文档中的图片显示更可靠。
- Markdown 图片的放大预览已恢复，查看大图不用再反复切换。
- 图片全屏预览窗体的布局、拖动和交互做了优化，放大查看时更顺手。

## 会话工作目录更清晰

- 会话 Shell 工作目录新增“在此目录 / 在隔离工作树”工作位置选择。
- 选择隔离工作树后，会明确约束模型在 `.pai/.worktree/` 下工作；只读权限下也会提示至少启用审批权限。
- 修复前端刷新时重复探测 Git 工作目录的问题；探测现在仅在打开工作目录面板时发生、按目录缓存至应用关闭，并在 Windows 下静默运行。

## 其他修复与调试改进

- 修复后端误把前端展示消息投影当成真实消息链路消费的问题，避免工具历史展示文本回流到模型上下文或持久化流程。
- 开发模式下可从消息气泡右键直接查看原始 `ChatMessage` JSON，更方便排查展示前后的真实消息结构。
