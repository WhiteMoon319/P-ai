# 变更日志

## 发布：v0.30.0

## 功能

- 远程联系人应答升级为独立委托流程：可在会话控制面板查看进度、结果和历史，也可取消任务；群聊支持更可靠的喊话防抖、在场判断和离场反思。
- 聊天支持批量归档，会话会立即从列表移出，后台继续完成归档维护；归档窗口也可直接将会话恢复为普通会话。
- Codex 用量面板支持查看并使用额度重置券，并新增 GPT-5.6 Sol、Terra、Luna 模型选项。
- 文件阅读器与 Markdown 中的本地文件链接支持直接打开目标文件；代码链接可携带行号定位，Mermaid 图中的文件链接也可使用。
- 文件阅读器标签页支持右键批量关闭，工作区目录在尚未打开文件时会自动展开。

## 修复

- 重做助理消息流式显示：回复完成、停止或失败时不再整段替换、闪烁、跳动、丢失正文或思考内容，已显示的内容保持稳定。
- 修复流式输出期间聊天画面被持续向下拉动、滚动锚点变化及完成瞬间列表弹跳的问题。
- Web 端与桌面端统一助理消息显示：发送后立即显示助理状态，完成时不再切换正文来源，工具、思考和正文顺序保持一致。
- Web 端流式期间可继续输入并粘贴图片；聊天历史图片可正常懒加载，不再出现 `method_not_found`。
- Web 文件阅读器与桌面端统一代码虚拟化读取，修复打开 JSON、TypeScript、Rust、Vue 等代码文件时内容区空白的问题。
- 修复 Web 端工具调用重复显示、委托结果文件链接无响应，以及本地文件链接无法在侧边栏打开的问题。
- 修复计划卡片、表情、图片等仅在回复完成时返回的信息需要刷新后才出现的问题；无流式事件的快速回复也可正常显示。
- Mermaid 支持模型常见的字面换行写法，减少图表因 `\\n` / `\\N` 输出而渲染失败。
- 修复 `.ts` 文件被误判为媒体文件、文件链接行号丢失，以及目录树打开文件后内容区空白的问题。
- 修复有内容的助理消息在停止、失败或前台恢复时被意外删除的问题；除用户主动撤回外，已显示消息不会被清除。
- 修复远程联系人回复正文被工具调用吞掉、工作目录变化后仍使用旧提示词，以及当前联系人会话不能及时看到新回复的问题。
- 修复设置页用量与存储统计卡顿、委托列表刷新缓慢、归档侧栏长标题撑开布局等问题。
- 修复模型数据库将模型标记为不支持多模态时，图片、音频、视频能力开关被禁用的问题；模型更新仍可自动填充能力，用户也始终可以手动调整。

## 优化

- 会话控制面板到达底部时立即显示，离开底部后短暂延迟隐藏，减少快速滚动时的闪烁。
- 面板标签改为 Chrome 式均分收缩布局，窄窗口下更易使用；归档与标签栏视觉样式更统一。
- 工具调用预览统一为单一列表样式，连续工具标记会合并显示，思考与工具明细可同时展开。
- 运行日志按等级着色，并统一关键运行日志的等级和中文状态文案，排查问题更直观。
- 用量概览和委托状态改用轻量缓存与快照读取，减少打开设置页和切换委托列表时的等待。
- Codex 回复默认使用较低可见详略度，在保留推理能力的同时减少冗长输出。

## 重构

- 聊天助理消息统一使用同一份内容块数据，桌面端、Web 端、流式态和完成态不再维护不同正文副本。
- 会话元数据与消息索引进一步迁移到 SQLite，降低大体量会话读取、统计和恢复成本。
- 清理已被新委托路由替代的远程联系人旧忙碌打断与快速请求路径，减少重复状态机。
