# 发布：v0.18.0

## 功能

- 聊天消息区新增“跳到上一条用户消息”入口，便于长对话中快速回到上一轮用户输入。
- 聊天数学公式能力补全，支持 `$...$` 行内公式、`$$...$$` 独占显示公式及多行显示公式，并在复制时尽量保留原始 Markdown / LaTeX 表达。
- MCP 运行链路适配 MCP 2025-11-25 内容模型，提升新版 MCP 服务与工具内容块的兼容性。
- 文件与资料读取能力升级，刷新 PDF 文本提取、PDF 页面渲染和 Office 文档抽取链路，提升复杂文档的读取兼容性。
- 新模型上下文估算覆盖更新，补齐新 OpenAI 模型 tokenizer 映射，让上下文窗口和 token 预算更准确。

## 维护

- 升级 RMCP、pdf_oxide、tiktoken-rs、hayro、undoc、katex、shiki、daisyui 等前后端关键依赖，并完成兼容性适配。
- 刷新 Tauri 核心运行时与 Rust 传递依赖锁定，跟进窗口、运行时、网络、TLS、WebView 与解析栈补丁。
- 移除未使用的 async-openai 与 captis 直接依赖，减少后端依赖面和旧截图依赖残留。
- VS Code 侧边栏扩展同步到 0.18.0，并重新打包验证安装包。

## 修复

- 修复会话流式串流与忙碌态污染，避免后台或旧会话事件影响当前前台会话运行态。
- 修复聊天流式窗口在可见流式消息持续增高时被底层虚拟滚动尺寸修正自动向下带走的问题，流式期间不再跟随 `adjustments` 驱动的滚动补偿。
- 修复新建会话后切换目标会话时受旧前台人格影响的问题，明确按目标会话读取快照并保留当前前台会话概览。
