# 发布：v0.36.2

## 界面显示可自由调节

- 新增 75%–150% 的连续界面尺寸调节，文字与常用控件会同步变化。
- 常用的 75%、100%、125% 与 150% 可一键切换；Markdown 标题、表格和代码仍会保持清晰的层级。
- 字体字重、思考和工具摘要等区域的显示层级已进一步校正，阅读更稳定。

## 链接与文件引用更顺手

- 聊天中的网页链接、本地文件链接和 `file:///` 链接现在支持尖括号包裹格式，例如 `<https://example.com>` 与 `<E:/项目/说明.md:12>`。
- 带空格或括号的链接更可靠，尖括号不会再显示在正文里。

## 聊天队列更符合预期

- 会话正在回复时，新发送的消息会安静地留在队列中，不会提前显示在当前对话内容里。
- 队列消息也不会提前写入本地消息缓存，实际开始处理后才会随正式历史出现。
