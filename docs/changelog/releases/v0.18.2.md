# 发布：v0.18.2

## 功能

- 聊天消息区新增“上一条/下一条用户消息”跳转按钮，并将回到底部入口调整为独立底部图标，长对话内移动更直接。

## 维护

- 清理 Rust 后端未使用代码，消除 `cargo check` 中长期出现的 dead code warning。

## 修复

- 修复远程访问登录态容易丢失的问题：登录后只保存 token，不再保存密码或密码摘要；后端支持多个有效 token 并滑动续期，避免侧边栏、设置页和不同浏览器入口互相挤掉登录态。
- 修复 web 模式下聊天输入区模型下拉菜单不跟随当前主题色的问题，Teleport 弹层现在会继承当前主题。
- 修复简单行内数学公式无法渲染的问题，减少 `$...$` 公式被误过滤的情况。
- 修复配置页侧栏滚动区域被标题栏顶开以及左右边距不一致的问题。
- 修复聊天窗口与侧边栏“从此消息开始创建会话分支”错误回退到上一条用户消息、导致分支漏掉当前消息的问题。
- 修复聊天窗口与侧边栏撤回消息时错误复用“回退到上一条用户消息”定位逻辑的问题，撤回与分支现在都直接作用于当前消息。

## 重构

- 拆分消息定位逻辑：仅“重新生成”继续使用“定位到对应用户消息”的专用路径，避免与撤回、会话分支共享错误语义。
