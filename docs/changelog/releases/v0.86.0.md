# v0.86.0

## 功能

- AI 操作桌面应用更可靠：支持等待窗口或元素出现、副屏窗口寻址、拖拽、剪贴板读写，后台点击改按窗口名和元素名定位，找不到时给出候选清单，脚本中途出错也会说明已执行到哪一步。
- 覆盖模式下打开文件后自动收起目录树，不用再手动切换才能看到内容。

## 修复

- 思考与执行字符数在流式回复时停在旧值，现在会持续增长到最新数字。
- 修复压缩重开对话后气泡永久停留在流式状态、与引导消息气泡并存的问题。
- 修复流式回复期间聊天区尾部留白被冻结、不再自适应的问题。
- 修复 Git 面板反复自动刷新停不下来的问题。
- 修复运行日志窗口不再自动跟随底部新日志的问题，滚动条改为常驻显示。
- 修复部门权限面板中 MCP 工具全部归入「其他」分组的问题。
- 修复用户消息在分享图片中重新折行的问题。
