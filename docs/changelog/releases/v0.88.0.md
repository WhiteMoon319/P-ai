# v0.88.0

## 功能

- 桌面操作新增后台操作模式与「移动鼠标」动作：助手无需切换窗口、不抢焦点即可对指定后台窗口截图、点击（含双击）、填文本、读文本、滚动与发按键，找不到目标时给出候选清单；脚本中途出错会说明已执行到哪一步。
- 后台任务监控面板：AI 启动的后台命令可在侧边栏实时查看运行状态、持续时长与输出进展；任务进度实时同步到网页端与 VS Code 侧边栏，切回前台后自动刷新为最新状态。
- AI 修改文件不再等待审批，删除文件改为移入系统回收站（macOS 为废纸篓），误删后可以找回；终端命令审批要求 AI 填写命令用途，审批卡会展示说明。
- 输入面板与提问卡统一为双层卡片，桌面与手机共用同一套布局，等待队列以「露头」方式提示，排队消息不再漏显。
- 右侧栏预览卡片墙重做，新增「历史委托」卡与「计划预览」卡；Git 卡会随 IDE、终端里的文件改动自动刷新。
- 会话列表新增精简视图模式，运行中的会话有更明显的状态提示。
- 新增「深度回忆」工具，可以从历史会话里找回某个话题的来龙去脉。
- 接入 OpenCode Go 端点时自动携带会话标识；Code X 支持 GPT-6（gpt-6-astra）。

## 修复

- 修复压缩重开对话后气泡停留在流式状态、流式回复期间尾部留白被冻结、思考与执行字符数停在旧值的问题。
- 修复会话忙碌时无法打开上下文占用入口，以及上下文占用与词元账单取数不对的问题。
- 修复从「批准计划执行」等非发送入口继续会话时回复收不到、界面卡在等待的问题。
- 修复调度日志把一轮工具循环的多轮合并成一轮的问题，现在按轮次分别展示。
- 修复 Git 面板反复自动刷新停不下来、运行日志窗口不再跟随底部的问题。
- 修复足迹墙「今天」视图凌晨时段漏统计、远程 IM 私聊消息归属错误、微信图片与文件收不到的问题。
- 修复便携版更新时程序被占用导致替换失败的问题，现在会等待程序退出后重试。
- Android 端发消息一直收不到回复、模型列表也加载不出来：请求缺少证书链导致 HTTPS 握手失败，现已恢复。
- Android 端「Android 专属」设置页内容超出屏幕后无法滑动，现在可以正常滚动。

## 性能

- 隐藏弹窗中的原始消息 JSON 与代码全文预览改为打开时才渲染，打开含超长思维链或大代码块的消息后滚动聊天不再周期性卡顿。
