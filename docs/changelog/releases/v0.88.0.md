# v0.88.0

## 功能

- 右侧栏预览卡片墙重做，新增「历史委托」卡与「计划预览」卡；Git 卡会随 IDE、终端里的文件改动自动刷新。
- 会话列表新增精简视图模式，运行中的会话有更明显的状态提示。
- 新增「深度回忆」工具，可以从历史会话里找回某个话题的来龙去脉。

## 修复

- 上下文占用与词元账单一直显示不对，现在会跟随会话最新进展。
- 会话正在输出时无法打开上下文预览面板，现在随时可以打开。
- 从「批准计划执行」等非发送入口继续会话时，回复收不到、界面卡在等待，现已恢复。
- 调度日志里一轮工具循环的多轮被合并成一轮，现在按轮次分别展示。
- 设置页内容紧贴导航栏、联系人卡片贴边错位，现已恢复内边距。
