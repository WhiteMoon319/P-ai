# 发布：v0.15.1

## 优化

- **聊天右侧栏**：委托、任务和工具评估项统一改为整项点击打开，补齐和任务一致的悬停高亮，并复用现有会话列表时间格式显示开始/完成时间。

## 修复

- **远程联系人**：新联系人会话现在会像普通会话一样注入初始摘要；当消息仓库还没有可续写 block 时，追加消息会自动兜底，避免新群消息进入后所有远程联系人会话一起报错。
- **前台同步**：运行态事件命中新远程会话时，前端会补拉远程会话列表，避免前端收到运行状态后因为本地列表缺项而静默不刷新。

## 其他

- **VS Code 侧边栏扩展**：随本次前端改动同步重打安装包，便于发布前验证。
