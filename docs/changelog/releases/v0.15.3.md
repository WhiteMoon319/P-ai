# 发布：v0.15.3

## 新增

- **会话快速请求**：统一记录远程 IM、标题生成、任务优化和工具评估等会话级轻量请求，并在右侧栏新增「杂务」页用于查看请求、回复和错误记录。

## 优化

- **杂务任务名称**：远程联系人会话里的杂务记录按具体轻量任务显示“回复判断”“忙碌打断判断”，新记录不再笼统显示为“远程 IM”。

## 修复

- **远程 IM 工具轮次回复**：远程 IM 联系人调度在工具调用前已生成的助理文本，会在工具结果持久化后自动发送给本轮绑定联系人；最终收尾自动发送改为只按最终回复尾段判定，避免任务期间说过的话被漏发或重复外发。
- **始终回复秘书判断**：始终回复联系人统一进入秘书决策方法内部短路通过，避免普通入场或忙碌引导在调用方按策略分叉；该短路不请求快速模型、不记录杂务、不输出秘书判断日志。

## 其他

- **VS Code 侧边栏扩展**：同步扩展版本号并完成 `pai-test.vsix` 打包验证。
