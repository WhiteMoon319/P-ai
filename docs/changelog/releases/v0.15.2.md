# 发布：v0.15.2

## 调整

- **快捷键设置**：快捷键页将录音键、录音测试、后台语音截图关键词与截图范围合并为“语音”卡片，聊天设置页不再重复展示后台语音截图设置。
- **用量管理**：移除聊天设置页的多媒体解析缓存卡片，改由用量页统一展示并清理。
- **会话列表**：新增置顶下方的“最近会话”分组，默认仅展开最近会话，其它分组默认折叠；最近会话额外纳入一小时内和所有未读会话。

## 修复

- **工具调用**：为 `get_session`、`recall`、`reload` 内置工具补齐空 `required` schema，避免 DeepSeek 等严格校验供应商拒绝工具调用请求。
- **后台唤醒**：后台唤醒开关改为即时写入配置、刷新录音热键探针并广播最新配置，避免仅切换设置页草稿导致运行时不生效。
- **会话接管**：当前会话绑定部门或人格失效时显示接管人选择/删除入口，避免聊天窗口卡死。
- **弹层输入**：原生选区清理收敛为弹层打开瞬间触发，避免全局清理持续打断委托等文本输入框。
