# 发布：v0.15.4

## 新增

- **助理空间工作区统一**：主助理会话统一落到助理空间工作区，减少会话切换时的工作区割裂，后续工具与记忆链路也更容易复用同一上下文。
- **更新提醒卡片**：应用内更新入口改为提醒卡片展示，支持跳过指定版本，并在可中断阶段提供取消更新操作。

## 优化

- **更新检查对话**：手动检查更新后会直接展示当前版本、最新版本、运行时类型和发布说明，下载入口与状态提示更完整。

## 修复

- **ready 快照重复自修复**：消息存储 ready 校验改为按持久化视角比较索引，避免把临时重建索引和磁盘索引误判为不一致，导致每次启动都重建会话快照。
- **更新取消状态**：更新中的取消按钮只在真正可取消阶段展示，取消中、完成、失败和重启就绪后的状态收口更一致，避免前端错误暴露不可用操作。
