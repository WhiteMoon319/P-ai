# v0.32.0

## 功能

- 文件阅读页新增文件标签右键菜单，可以在 PAI 文档窗口中打开文件、打开文件所在文件夹，或使用系统默认程序打开文件。
- 会话菜单新增“在浏览器打开”，可以直接在浏览器中打开当前会话。
- 移除已无法正常使用的独立聊天窗口入口，保留浏览器和侧边栏中的会话查看功能。

## 修复

- 修复接近全屏时单击标题栏会意外缩小窗口的问题；现在只有实际拖动标题栏时才会还原窗口尺寸。
- 修复“在浏览器打开”失败时显示错误提示不准确的问题。
- 修复部分 Codex 模型在模型列表中显示不完整或上下文容量不正确的问题。
- 修复会话列表偶尔重复刷新、远程联系人在闭嘴后仍继续回复，以及回复期间无法录音的问题。
- 修复会话整理期间无法发送新消息的问题。
- 修复连续发送多条消息时队列一次性取出全部消息的问题；现在会按顺序逐条处理，标记为引导的消息仍会优先一起处理。

## 优化

- 优化图片、音频和视频的解析提示：当前消息中的图片已经可见时，不会再重复请求解析；需要查看不可见图片或解析音视频时再进行处理。
- 优化工具结果展示，较大的结果不会一次性占满对话上下文，仍可按需继续查看完整内容。

## 其他

- 优化 Web 端与桌面端的记忆、会话分组和工作区文件阅读体验，减少两端行为不一致的情况。
