# v0.59.0

## 功能

- 文件阅读器新增 Git 面板：可在「文件/Git」之间切换，查看工作区与暂存区改动、查看 diff、暂存与取消暂存、丢弃改动、提交、储藏、切换/新建/删除分支、抓取/拉取/推送/同步，以及浏览提交历史与提交图；点击历史提交可直接查看该次提交的改动。
- 工具审查中的 diff 卡片升级为语法高亮显示，代码颜色按文件语言渲染，底色与行号结构保持不变。
- macOS 应用支持自动更新：新版本发布后会自动提示并完成升级，无需手动重新下载安装。
- 文件阅读器标签页支持鼠标中键直接关闭，无需先激活再点关闭按钮。
- 文件标签页视觉优化：激活标签更突出，标题过长时渐隐显示，不再溢出挤压其他标签。
- 打开文件失败时，提示中提供「打开所在文件夹」入口，方便定位文件位置。

## 修复

- 修复足迹统计中同名模型在不同供应商下被合并显示的问题：不同供应商使用同名模型时，用量现在各自分开统计，不再串到别的模型名下。
- 修复部门人格或模型缺失时整个部门消失的问题：现在仅提示缺失并保持该选项可选，不再整体消失。
- 修复部门人格被删空后部门消失的问题：自动回退到助理人格，避免部门不可用。
- 修复聊天中缺失项交互兜底：避免用户遇到全空界面或键盘卡死。
- 修复窄屏下侧边栏浮层留缝的问题：浮层现在全屏覆盖，不再保留主区缝隙。
- 修复足迹墙「最活跃时段」中英文混杂的问题：现在按界面语言显示。
