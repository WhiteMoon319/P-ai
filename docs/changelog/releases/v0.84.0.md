# v0.84.0

## 功能

- 后台任务监控面板：AI 启动的后台命令可以在侧边栏实时查看运行状态、持续时长和输出进展。
- 会话工作面板的监控入口升级：委托、任务、后台进程同时运行时直接显示组合数量，单类运行保持原有详情样式；监控概览页集中查看所有进行中的事项。
- 任务状态变化现在实时同步到网页端与 VS Code 侧边栏，各端打开同一会话看到的运行进度保持一致；断网恢复或窗口切回前台后，进度会自动刷新为最新状态。
- 接入 OpenCode Go 端点时自动携带会话标识，修复请求被 OpenCode 以「缺少会话头」拒绝的问题。
- Code X 支持 GPT-6（gpt-6-astra）：可选模型清单新增该模型。
