# v0.58.0

## 功能

- 委托状态在打开会话时立即刷新，会话工作区栏的活跃委托展示不再依赖监控面板的委托标签页是否打开。
- 电脑仅有 Windows PowerShell 5.1 时，助手会主动引导安装 Git for Windows（自带 Git Bash），Git 下载失败时再尝试安装 PowerShell 7，完成后提示重启应用生效。
- 手机模式下聊天输入框默认收起为单行圆角输入条，可一键展开为完整输入模式，发送或离开输入框后自动收回。
- 上传附件期间先显示处理中占位，文件读取完成后才显示预览。
- 切换会话更流畅：消息记录、会话列表、已读状态的加载都在后台进行，连续快速切换会话也不会卡住界面。
- 降低磁盘读写频率：会话数据按需读取、避免重复写入，减轻硬盘负担，延长使用寿命。

## 修复

- Shift+滚轮切换会话现在跟随会话列表的实际显示顺序（置顶、最近、工作区/频道分组），不再按旧顺序滚动。
- 文件阅读器打开大文件或大目录时不再卡住界面，内容读取在后台完成。
