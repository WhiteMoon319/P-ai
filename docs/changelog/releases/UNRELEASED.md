## 修复

- 允许同一会话在主窗口、独立窗口和 VS Code 侧边栏同时打开，不再触发占用锁、强制切入或自动退回系统会话。
- 修复流式思维链计数器在增量输出时反复重新汇总已累计内容的问题，改为随 reasoning delta 增量更新计数。
- 修复聊天弹性空间锚点选择：找不到用户消息和压缩摘要时允许回退到“计划开始”分隔条，但不再回退到最后一条普通可见消息，避免非用户内容误触发上推参照。
- 修复文件阅读器虚拟代码块高亮跨块丢失语法状态的问题，避免多行字符串、注释等被错误渲染。
- 修复文件阅读器切换文件时沿用上一文件滚动位置的问题，新文件默认从首行开始显示。
- 修复远程 IM 渠道删除后仅在界面消失、重启后又恢复的问题，并在删除时停止对应渠道运行态。
- 修复远程 IM 渠道启动、停止和端口绑定失败等生命周期日志未同步到渠道日志的问题，并避免渠道日志暴露本机私有状态路径。
