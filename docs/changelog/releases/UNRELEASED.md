## 功能

- 新增（remote-im）：远程联系人会话在输入区上方提供独立悬浮能量仪表盘，展示后端权威的能量、恢复速率和在场状态；仅在可见远程会话订阅推送，前台恢复时以水位校验回补冻结期间错过的快照。
- 优化（remote-im）：群聊默认采用智能判断且默认不主动入场；新增独立的“什么时候应该回答”提示词和恢复默认功能，避免对无关、重复及针对助理的点评反复插话。
- 优化（chat）：会话控制面板支持右键切换 IDE 桥文件标签与侧边文件标签；VS Code 侧边栏固定显示 IDE 桥标签、隐藏侧边文件标签，Web 页面可读取 VS Code 同步的当前打开文件，关闭文件或阅读器侧边栏会及时清理侧边候选标签。
- 优化（chat）：左右侧栏在扩展后窗口总宽度不超过当前屏幕时向窗口外展开，空间不足时保留现有嵌入/覆盖行为；窗口位置与尺寸更新保持一致，避免左侧展开跳动和重复收缩后宽度累积。

## 修复

- 修复（task）：`task.complete` 恢复为普通工具结果，仅更新任务终态并将结果回喂模型，不再错误终止当前 LLM 调度或直接将完成结论替代助理回复。
- 修复（window）：窗口布局启动时仅读取一次并常驻内存，变化后由单一队列最多每 60 秒异步写盘，避免开发重启期间窗口事件并发读写导致聊天窗口概率性恢复为小方窗；无有效布局时恢复为聊天窗口默认纵向尺寸。
- 修复（read-media）：统一模型协议动态解析为“手动协议优先，Auto 先匹配 Base URL、再匹配完整模型名”，并按路径优先识别百炼、DeepSeek、火山、Kimi、Mimo 及 Token Plan 的 OpenAI/Anthropic 兼容端点；直连 QWEN 使用独立媒体载荷且音频发送裸 Base64 与 `format`，OpenCode Go 的 QWEN 仅在 `read_media` 内按官方 `/messages` 与 `x-api-key` 兼容并明确拒绝该端点不支持的音频，Mimo/OpenCode Go 的 OpenAI 兼容端点继续使用 Bearer。
- 修复（remote-im）：群聊从离场重新入场时，当前 block 在触发消息前少于 14 条消息将直接进入应答，不再无意义写入唤醒压缩摘要；计数仅取 block 消息数减去触发消息，走 SQLite/JSONL 索引且不改变既有索引格式。
- 修复（remote-im）：完善群聊状态机 V2：`Away` 时仅按入场模式开始观察，`Present` 期间普通消息继续进入巡检并刷新耐心计时；回复正文只允许当前应答委托在严格超过 200% 多语言单位阈值时执行有归属杂务改写，联系人历史、外发载荷、委托结果与能量结算统一使用同一最终正文；能量生成前不预扣，实际外发后允许在正负最大能量范围内结算并按需恢复。
- 修复（remote-im）：移除会将入站消息错误短路为“渠道未开启助理激活”的废弃渠道字段；渠道启用和联系人收信通过后，统一由联系人点名/入场状态机决定是否调度助理。
- 优化（remote-im）：入站、入场、巡检和自动发送日志改用渠道名、联系人名与正文摘要；联系人日志以隐藏的稳定关联键筛选，不再因同名联系人串日志或向用户暴露内部 ID。
- 修复（remote-im）：新发现的联系人默认关闭收发，首条消息仅建档并忽略，须由联系人开关明确允许后才会进入后续处理。
- 修复（chat）：上下文压缩与远程唤醒压缩会保留助理工具阶段的正文，不再将仅存在于工具调用记录中的正文误判为空消息后丢弃。
- 修复（chat）：保留对话改为按目标 block 从最新消息反向读取，最多继承块头摘要中的 `## 保留对话`，不再跨 block 捞取旧原始消息；预算累计支持 Token 与 KiB 两种模式，根据真实会话 10,000 Token 窗口评估结果，当前硬编码使用 26 KiB。
- 修复（tools）：统一按执行部门、会话类型、联系人能力与 MCP 状态装配合法工具，修复白名单未授权工具仍被注入的问题；权限、缓存或工具读取异常时仅跳过受影响工具，不再中断聊天或委托。
- 修复（tools）：收口内置工具权限表；远程群聊及其应答委托禁用 Goal，联系人会话中的远程应答委托仍可创建归属该联系人的任务，普通委托不再获得 task / plan 提示词。
- 修复（remote-im）：远程群聊委托发送图片时可回退到联系人会话的持久绑定；Markdown 图片会转换为实际图片外发，并忽略梗图模板附带的“来源：文件名”文字。

## 重构

- 重构（remote-im）：将消息头过滤、闭嘴/张嘴、什么时候应该回答、在场耐心和群聊巡检能量等静态行为参数收口为渠道统一设置；联系人仅保留路由、应答策略和独立动态账本。设置改为居中可滚动卡片，保存后以 best-effort 失效并重排待处理群聊批次；配置或重排读取失败时只回退渠道默认参数并继续处理。
- 重构（remote-im）：以联系人级状态机重构远程群聊点名/非点名巡检、冷却、能量、焦点和回复长度控制；增加发送前持久标记、结果不确定防重发、账本提交重试与联系人完整设置原子粘贴，局部读取、锁、委托善后或存储异常时保留批次并降级继续，不再莫名中止后续业务。
- 重构（remote-im）：远程入站消息在收信调用内完成平台消息原子去重与会话落库，私聊调度只保留已保存消息引用，群聊巡检到期后才按冻结范围结算能量且同一正面词每轮只计一次，消息出现不再受聊天队列和 AI 工作阻塞。
- 重构（attachments）：统一以消息 `Attachment` 的绝对路径作为图片、音频及文件的单一事实源，保留旧媒体协议只读兼容；本地、侧边栏与远程渠道按原始顺序投影附件，图转文、二进制物化、缓存和 provider 适配失败时仅跳过受影响附件并保留可见路径提示，不再中断聊天、委托或远程入站。
