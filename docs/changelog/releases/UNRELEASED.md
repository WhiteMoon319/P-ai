## 修复

- 修复流式输出期间消息行重叠的问题：上一轮「消除流式 Layout Thrashing」的测高优化引入了虚拟列表测量短路——同一行元素且已有缓存高度时跳过 `measureElement`，流式增长中的行高度依赖异步 ResizeObserver 兜底，滞后帧内后续行（如用户消息）按旧高度定位，与增长中的助理消息重叠；现回退该短路与缓存测量，恢复每帧主动测量，流式消息与用户消息不再出现在同一高度。
- 修复切换会话后滚动位置卡在中间的问题：原实现用单次 `scrollToEnd` 定位，切换瞬间新会话的行尚未挂载、高度全是估计值（每条 1px），目标偏移基于严重低估的 totalSize，滚动后停在半路且无后续修正；现改为「最后一条消息可见」意图——滚动目标锚定最后一条消息，行挂载与测高期间持续重试 `scrollToIndex` 直到其进入视口，用户主动滚动（滚轮/触屏）立即取消意图，不再与用户对抗。
- 修复流式消息串会话的问题：前端绑定流式 channel 的事件本身不带会话标识，bound guard 原先只校验 channel 序列号、不校验会话归属，切换会话瞬间旧 channel 的 `round_completed`（携带完整 `assistantMessage`）可能穿过 guard 被合并进当前会话的消息列表；现为 bound guard 增加前台会话匹配，切走后旧 channel 事件一律丢弃，后台会话的完成消息改由全局事件与切换快照兜底恢复。
