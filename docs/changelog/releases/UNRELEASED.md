## 修复

- 修复（window-drag-restore-default-size）：标题栏拖动窗口时，若当前窗口已最大化或尺寸已接近屏幕 92%，先恢复到默认尺寸再继续拖动，避免贴边放大后直接拖动仍保持近全屏尺寸。
- 修复（web-settings-native-actions）：网页端接通用量概览 API，并隐藏设置页、聊天工作区与文件阅读器中的本机目录打开入口，避免浏览器环境暴露不可用的桌面能力。
- 修复（web-prompt-preview-bridge）：网页端请求体预览接通会话列表与系统提示词预览桥接，修复会话下拉框无内容、预览功能不可用的问题。
- 修复（markdown-list-marker-fidelity）：聊天 Markdown 渲染改为按列表项保留原文编号值，避免有序列表在夹杂无序子项或使用非常规编号时被自动改写为连续序号。
- 修复（chat-summary-state-misuse）：未归档会话、前台会话选择、聊天索引归档判定与请求体预览不再把 `summary` 当作生命周期依据；`summary` 仅保留为内容字段，归档/未归档判断统一只看正式归档字段。
