## 修复

- 会话列表中忙碌会话的预览统一显示“正在输入......”，头像改为优先显示会话绑定助理人格，避免最近一条为用户消息时误显示用户头像。
- 从外链打开文件阅读器文件时，如果目标位于当前目录栏根目录下，会自动展开目标所在文件夹并滚动到对应文件。
- 复制单条消息、多选复制和分享导出时过滤内部 `[toolcall:...]` 标记，避免工具渲染锚点泄漏到用户可读文本。
- 系统原生通知标题改为优先显示会话标题并拼接部门名，失败通知追加失败尾缀；人格名下沉到通知正文，便于区分后台完成或失败来自哪个会话。
- 收缩远程联系人回复工具集，模型侧不再提供即时回复或不回复工具；普通文字统一走最终回复自动外发，联系人专用工具仅保留附件发送，并补充远程联系人处理前先确认已看到的接口提示。
- 修复远程唤醒摘要在旧消息瘦身或超长截断后丢失远程发言人身份的问题，并让摘要中的助理发言人使用当前会话真实人格名而非固定“助理”。
- 修复聊天存储升级可能阻断启动、重复触发迁移及与会话读取并发的问题，并支持基于 V2 blocks 真相层恢复 `building` 或索引不一致的会话后迁移至 V3。
- 修复远程群聊分支生成摘要时丢失消息发送者身份、将群友昵称错误显示为“用户”的问题；保留对话现在直接读取消息 `origin` 中的发送者昵称，且不再混入群名或渠道名。
