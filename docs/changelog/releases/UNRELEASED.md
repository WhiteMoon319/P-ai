# 未发布

## 功能

- 桌面端会话菜单改为在浏览器打开当前会话，打开后 Web 端会直接进入目标会话；旧的独立聊天窗口入口已移除。

## 维护

## 修复

- 修复 Codex 协议模型列表在新增 GPT-5.6 后遗漏 GPT-5.5 的问题；移除已不再支持的 `gpt-5.2`，普通 Codex 模型默认上下文窗口设为 256K，`gpt-5.3-codex-spark` 保持 128K。
- 修复会话概览水位更新封装：单会话水位更新现在统一自动广播该会话最新概览项，并移除会话通知投递后的重复全量广播与聊天用量累计造成的无效概览广播。
- 修复远程联系人群聊已进入闭嘴后仍继续说话的问题：命中闭嘴时会立刻中止该联系人在途应答委托，并在自动发送与真正外发前再次拦截。
- 修复助手流式回复期间录音按钮无法启动的问题，用户现在可以在等待回复时继续录入下一条消息。
- 修复会话上下文整理（压缩）期间按 Enter 无法发送消息的问题，新消息现在会正常进入聊天队列。

## 优化

- 统一限制 Shell、MCP 与内置工具的大型返回结果：最多保留 2,000 行或 50 KiB 头尾预览，完整内容保存到 `tool-output` 目录供搜索和按范围读取，避免少量工具调用耗尽模型上下文。

## 重构

- 重构全部内置工具与 MCP 的结果通道：模型现在直接接收原文或紧凑可读文本，Shell 使用 Codex 风格执行头；控制状态、撤销记录与媒体改由独立元数据和内容部件传递，不再依赖 JSON 包装正文。
- 统一桌面端与 Web 端的记忆列表、删除、导入导出和混合检索业务实现，避免两端修改不同步；Web 端对导出到本机路径明确返回不支持。
- 统一桌面端与 Web 端的记忆供应商测试、绑定和索引同步状态业务，供应商规则调整后无需分别维护两套实现。
- 统一人格私有记忆的计数、回忆模式和禁用规则；Web 端不再把私有记忆导出到服务端文件系统。
- 统一会话分组排序的读取与保存逻辑，桌面端与 Web 端共用同一套校验和状态更新规则。
- Web 端明确禁止触发桌面原生通知和重启宿主应用，避免远程页面越过本机能力边界。
- 恢复 Web/侧边栏自有的工作区目录与文件阅读接口；仅禁止唤起宿主 Windows 文件窗口，不再错误拦截目录浏览和文件读取。
