# 发布：v0.36.0

## 远程联系人更好用

- 远程会话新增能量仪表盘，可直接看到当前能量、恢复速度和在线状态；回到前台后会自动补齐期间错过的状态更新。
- 群聊默认更安静：助手会先判断是否真的需要发言，减少无关插话、重复回复和对别人消息的点评。
- 群聊重新加入、持续巡检和自动回复的衔接更可靠，网络波动或处理超时也不会重复发送同一条消息。
- 新发现的联系人默认关闭收发，确认开启后才会继续处理消息，避免误触发。
- 联系人和群聊日志改为显示渠道名、联系人名和内容摘要，更容易定位问题，也不会暴露内部编号。

## 聊天、文件与侧边栏

- 图片、音频和文件现在统一按原始顺序展示；单个附件解析失败时会保留文件提示，不会影响整条消息或委托继续执行。
- 会话控制面板支持右键切换 IDE 文件和侧边栏文件标签；VS Code 侧边栏会同步当前打开的文件，关闭文件后候选标签会及时清理。
- 左右侧栏在屏幕空间足够时会自动向窗口外展开，空间不足时保持原有布局，反复开关也不会让窗口越变越宽或位置跳动。
- 上下文压缩会保留助手在工具阶段已经生成的正文，保留对话也只继承当前目标内容，减少无关历史和内容丢失。
- 任务完成后会正常回到助手回复流程，不会因为完成一个任务而提前终止整轮对话。

## 工具与模型兼容性

- 工具权限按当前会话、联系人能力和 MCP 状态统一校验，未授权工具不会再被错误提供；局部读取或缓存异常也只跳过受影响工具。
- Gemini 在调用图片、音视频等工具后可以继续正常回复，不再因内部续接信息缺失而中断。
- 图片和音频读取会根据手动协议、服务地址和模型名自动选择正确的供应商接口，兼容更多百炼、DeepSeek、火山、Kimi、Mimo、QWEN 及 OpenCode Go 配置。
- 远程委托发送 Markdown 图片时会直接发送实际图片，并自动去掉模板附带的文件名来源文字。
