# v0.57.0

## 功能

- 会话列表的聚合旧会话条目新增摘要预览：未读或 7 天内有更新的条目默认展开显示最近消息摘要，其余条目悬停时展开；移除悬停时的系统默认提示气泡
- 新增 Alt+S 兜底发送快捷键：任何发送模式下均可使用，输入法占用回车键时也能快速发送消息
- 输入法下按回车确认发送的响应更快：回车确认窗口从 100ms 收窄到 10ms，发送不再拖沓
- 欢迎页运行时依赖提示收敛为只保留 ripgrep（rg）一项：仅当未安装时显示提示卡片并说明用途，可一键安装，也可「别再问我」不再提示；已安装或无需检测时不再出现该卡片，Git 与 Node.js 不再在欢迎页提示
- MCP 设置页新增 Node.js 缺失提示：检测到未安装时显示常驻提示卡片，可一键安装，安装完成后自动消失

## 修复

- 修复 Windows 通知中心显示为 PowerShell 图标/名称：应用启动时设置进程级 AppUserModelID，与安装器注册的快捷方式身份一致，通知恢复显示 PAI 品牌
- 修复切回前台时流式恢复失效：输入面板忙碌但没有流式消息时（通讯通道已断、消息列表无新内容），现在会判定为落后并立即刷新当前会话接回，不再静默卡住
